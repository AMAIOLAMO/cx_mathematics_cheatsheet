\chapter{Bounds, Minimum and Maximum}

\section{Finding Tight Intervals}
Recall the definition of $\min$ and $\max$ functions from the chapter \textbf{Range Manipulation}'s \textbf{Value Clamping} section.

We can generalize the $\min$ and $\max$ function to include more values :3

For $\min$:
\begin{center}
        $\min(a_1, a_2, a_3, ..., a_n) = \min(a_1, \min(a_2, a_3, ..., a_n))$
\end{center}

And for $\max$:
\begin{center}
        $\max(a_1, a_2, a_3, ..., a_n) = \max(a_1, \max(a_2, a_3, ..., a_n))$
\end{center}

For example, $\min(1, 4, -4) = \min(1, \min(4, -4))$. Here we can evaluate from the inside to the outside.
So $\min(4, -4) = -4$ and finally $\min(1, -4) = -4 = \min(1, 4, -4)$. Same should apply to the generalized $\max$ function!

In other words:
\begin{itemize}
    \item $\min$: Returns the minimum among all the values $a_i$.
    \item $\max$: Returns the maximum among all the values $a_i$.
\end{itemize}

By using this generalized $\min$ and $\max$ functions, we can actually find the bounding range of a set of values,
for example, if we have a set of values denoted by $a_i$, and there are $n$ of them (i.e. the first element is $a_1$ and last is $a_n$),
then, the interval that \textbf{tightly} includes all values is defined as:
\begin{center}
    $[\min(a_1, a_2, a_3, ..., a_n), \max(a_1, a_2, a_3, ..., a_n)]$
\end{center}

For example, if we have values $1, 4, 5, -2, 3$, we can find it's tight bound as:
\begin{center}
    $[\min(1, 4, 5, -2, 3), \max(1, 4, 5, -2, 3)] = [-2, 5]$
\end{center}

\section{Finding Bounds in Higher Dimensions}
This can be very useful if we extend this to two or more dimensions,
for instance, we can find the bounding box in two dimensions if we have a list of 2D points $P_i = \begin{pmatrix}x_i & y_i\end{pmatrix}$
and you have $n$ points represented in cartesian coordinates, then:

First we find the $\min$ bound of all 2D points by simply finding the minimum of each axis for every point:
\begin{center}
    $P_{min} = (\min(x_1, x_2, x_3, ..., x_n), \min(y_1, y_2, y_3, ..., y_n))$
\end{center}

Then we find the $\max$ bound of all 2D points with the same procedure, just using $\max$ function instead of $\min$:
\begin{center}
    $P_{max} = (\max(x_1, x_2, x_3, ..., x_n), \max(y_1, y_2, y_3, ..., y_n))$
\end{center}

As you can see, we are simply finding the $\min$ and $\max$ of each axis. Just like how we calculate for tight bounds for
a regular tight bound in a number line!

The reason why the result is actually two points $P_{min}$ and $P_{max}$ is because, these two points define an \textbf{axis-aligned bounding box}!

\sgap
For example, if we have a few points $(5, 0), (0, 2), (1, 9)$, then their tight bounds are:
\begin{center}
    $P_{min} = (\min(5, 0, 1), \min(0, 2, 9)) = (0, 0)$ and
    $P_{max} = (\max(5, 0, 1), \max(0, 2, 9)) = (5, 9)$
\end{center}

The $5, 0, 1$ are the $x$ of all points, and $0, 2, 9$ are the $y$ of all points :3

\sgap

\sgap

Hopefully you can see all red points are included in this box formed by connecting the corners using the two calculated blue points!

In fact, it is called \textbf{axis-aligned} because it is aligned with the $x$ and $y$ axis of this 2D plane :D

\sgap
Of course, this actually can be extended to any dimension! As long as you find the minimum and maximum of each axis respectively.
